# Licences of the data

| Material | Licence |
|---|---|
| Checklists produced by this work (`output/checklists/`: `checklists_by_area.xlsx`, `checklists_all_areas.csv`, `checklists_column_dictionary.csv`) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Manual-review files produced by the authors (`Input/processed/`) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Code (`R/`, `setup_renv.R`) | MIT (see `LICENSE`) |
| Third-party input data (GBIF, BBPAO, EASIN, WCVP, WFO, tree registers, etc.) | Original licence of each source; see `Input/README_input.md`. Redistributed here only where the source licence allows it. |

The checklists incorporate information derived from GBIF occurrence downloads
(cited by DOI in the manuscript). Licences of the individual GBIF records (CC0, CC BY or CC BY-NC)
are not reproduced here: they are documented on the GBIF download DOI pages, which apply to the underlying
occurrence records. Please also cite the original data sources when reusing the checklists.
